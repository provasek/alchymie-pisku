# Alchymie Písku

Interaktivní 2D fyzikální a chemický sandbox (Falling Sand) na HTML5 Canvasu.

## Prvky a reakce
- **Sypké & Pevné:** Písek, Kámen, Dřevo, Kov, Střelný prach, Semínko, Rostlina, Sklo, Led
- **Kapaliny:** Voda, Láva, Kyselina, Olej
- **Energie & Plyny:** Oheň, Elektřina, Kouř, Pára

## Ovládání
- **Levé tlačítko myši / dotyk:** kreslení vybraným prvkem
- **Pravé tlačítko myši:** guma
- **Mezerník:** pauza / spuštění simulace
- **C:** vyčistit plátno
- **`[` / `]`:** zmenšit / zvětšit štětec
